# Quill Meetings — Claude Code plugins

The plugin marketplace for Claude Code skills from [Quill Meetings](https://quillmeetings.com).

## Use

```
/plugin marketplace add quillmeetings/claude-plugins
/plugin install quill-deep-analysis@quillmeetings
```

Add the marketplace once; install any skill below with `@quillmeetings`.

## Skills

| Skill | What it does | Repo |
|---|---|---|
| **quill-deep-analysis** | Deep map/reduce research over your Quill meeting corpus → fact-first analytical report with a dated timeline and drill-down sub-reports. | [`claude-skill-quill-deep-analysis`](https://github.com/quillmeetings/claude-skill-quill-deep-analysis) |
